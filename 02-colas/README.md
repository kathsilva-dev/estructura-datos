# Colas (FIFO: primero en entrar, primero en salir)

## Operaciones que debo dominar
`encolar`, `desencolar`, `frente`, `estaVacia`, `estaLlena`, `tamaño`

## Ejercicios en orden de dificultad

Para cada uno: pseudocódigo en papel con la plantilla de 7 pasos y después C++.

- [ ] 1. Cola con **arreglo lineal**. ¿Qué problema aparece después de varias operaciones?
- [ ] 2. **Cola circular** con arreglo (resuelve el problema anterior con aritmética módulo).
- [ ] 3. Cola con **lista enlazada** (punteros a frente y final).
- [ ] 4. **Cola de prioridad** simple (los elementos salen según su prioridad).
- [ ] 5. Implementar una cola usando **dos pilas**.
- [ ] 6. Invertir los primeros K elementos de una cola usando una pila.

## Proyecto
**Simulador de la fila de un banco:** los clientes llegan en tiempos aleatorios, hay N cajeros y el programa calcula el tiempo promedio de espera y el largo máximo de la fila. Prueba con 1, 2 y 3 cajeros y compara los resultados.
